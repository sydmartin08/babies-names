Setup & Data Pipeline

The data is sourced directly from the US Social Security Administration, containing records of every registered birth in the United States from 1880 through 2025.

View R Code 
library(tidyverse)
library(plotly)

# List all annual text files in the data directory
files <- fs::dir_ls("data", glob = "*yob*.txt")

# Read, aggregate, and calculate annual proportions among female births
babies <- read_csv(
  files,
  id = "file",
  col_names = c("name", "sex", "count"),
  show_col_types = FALSE
) |>
  mutate(year = parse_number(file)) |>
  select(-file) |>
  filter(sex == "F") |>
  group_by(year) |>
  mutate(prop = count / sum(count)) |>
  ungroup()

The Last Decade (2016–2025)

Over the past ten years, the popularity of the name Sydney has experienced a steady, noticeable decline.

sydney_recent <- babies |>
  filter(name == "Sydney", year >= 2016) |>

ggplotly(p_recent, tooltip = "text") |>

Key Takeaways:

  • Halved in 10 Years: In 2016, Sydney represented 0.13% of all female births (2,322 babies). By 2025, that proportion fell to 0.05% (873 babies).
  • Consistent Trajectory: Aside from a slight uptick in 2024, the downward trend has been remarkably steady year-over-year.

Two Defining Patterns:

  1. The Turn-of-the-Century Phenomenon: Sydney was virtually unheard of as a female name for most of the 1900s (under 0.01%). Starting in the late 1980s, it surged dramatically, peaking in 2000 at 0.56% of all female births (over 10,200 babies).
  2. The Modern Correction: Since its peak around 2000, the name has seen an orderly decline, moving toward a low and stable long-term equilibrium.

Future Projections (2026–2035)

Where is the name headed next? We modeled the recent ten-year trend using an exponential decay model, which captures natural stabilization as popularity approaches baseline levels.

View R Code 
# Fit exponential model on 2016-2025 observations
fit_exp <- lm(log(prop) ~ year, data = sydney_recent)

# Baseline annual births for count estimations
birth_baseline <- 1607000

# 10-year projection
future_years <- tibble(year = 2026:2035) |>
  mutate(
    prop = exp(predict(fit_exp, newdata = tibble(year = 2026:2035))),
    count = round(prop * birth_baseline),
    type = "Projected",
    tooltip = paste0(
      "<b>Year:</b> ", year, " (Projected)<br>",
      "<b>Est. Count:</b> ~", scales::comma(count), " babies<br>",
      "<b>Share:</b> ", scales::percent(prop, accuracy = 0.01)
    )
  )

historical_recent <- sydney_recent |>
  select(year, prop, count, tooltip) |>
  mutate(type = "Observed")

combined_trend <- bind_rows(historical_recent, future_years)

p_proj <- ggplot(combined_trend, aes(x = year, y = prop, color = type, text = tooltip, group = type)) +
  geom_line(linewidth = 1.3) +
  geom_point(size = 2.8) +
  scale_color_manual(values = c("Observed" = "#6366f1", "Projected" = "#f43f5e")) +
  scale_x_continuous(breaks = seq(2016, 2035, by = 2)) +
  scale_y_continuous(labels = scales::label_percent(accuracy = 0.01)) +
  labs(
    title = '10-Year Forecast for "Sydney" (2026–2035)',
    x = "Year",
    y = "Percentage of Female Births",
    color = "Data Series"
  ) +
  theme_minimal(base_size = 12) +
  theme(
    plot.title = element_text(face = "bold", size = 13, color = "#1e293b"),
    axis.title = element_text(size = 11, color = "#64748b"),
    legend.position = "bottom",
    panel.grid.minor = element_blank(),
    panel.grid.major = element_line(color = "#f1f5f9")
  )

ggplotly(p_proj, tooltip = "text") |>
  config(displayModeBar = FALSE)

Forecast Insights:

  • Projected Frequency: By 2035, Sydney is anticipated to represent around 0.02% of newborn girls (~350 babies per year in the US).
  • Decay vs. Linear: A naive linear model would predict impossible negative numbers by 2032. The exponential model accurately reflects how name usage tapers gradually into a steady classic niche.
